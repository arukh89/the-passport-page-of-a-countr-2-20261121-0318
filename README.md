An invented passport spread for the Republic of Talmar — a small island nation reachable only by ferry. Holder Mara Voss, born 14 June 1992 in Port Meridian; passport issued 12 March 2024, valid to 11 March 2034. The spread pairs the data page (drawn portrait, machine-readable zone with ICAO check digits) with the visa page: a Dravnia visitor visa, six arrival/departure stamps from Dravnia, Svelmark and Ostara — every stamp after the date of issue, in chronological order — and a ferry passage tax stamp of 40 crowns.

The image is drawn from code (`render.py`, Pillow, build-time only) and committed as `entry.png`; `main.py` (standard library only, no network) copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
